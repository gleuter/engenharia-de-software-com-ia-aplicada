Olá! Vamos falar sobre **tensores** no TensorFlow.js de forma bem didática. 😊

## O que são Tensores?

Pense nos tensores como a **linguagem universal do TensorFlow**. O próprio nome "TensorFlow" vem de *Tensor* (tensor) + *Flow* (fluxo) — ou seja, o fluxo de tensores através de um grafo computacional.

No contexto do JavaScript e TensorFlow.js, **tensores são estruturas de dados que contêm apenas números**, organizados em arrays multidimensionais. Eles são a forma como representamos dados para que algoritmos de machine learning possam processá-los e aprender padrões.

## Por que não usamos objetos JavaScript diretamente?

Aqui está um ponto crucial: **o TensorFlow.js não entende objetos JavaScript, strings ou tipos primitivos**. Ele só trabalha com números.

Veja este exemplo do contexto:

```javascript
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];
```

Esse array de objetos é perfeito para nós, desenvolvedores, mas **o TensorFlow.js não consegue processar isso diretamente**. Precisamos converter para uma representação numérica — um **tensor**.

## Como transformar dados em Tensores?

O processo é transformar características categóricas (como "cor preferida") em números. Uma técnica comum é o **one-hot encoding** (codificação one-hot):

| Pessoa | Azul | Vermelho | Verde |
|--------|------|----------|-------|
| Erick  | 1    | 0        | 0     |
| Ana    | 0    | 1        | 0     |
| Carlos | 0    | 0        | 1     |

Cada cor vira uma coluna, e marcamos com **1** a cor da pessoa e **0** nas demais. Isso cria uma matriz numérica — que é um **tensor 2D** (uma matriz)!

## Representação em JavaScript

No TensorFlow.js, você cria tensores usando a API `tf.tensor()`:

```javascript
// Exemplo conceitual (não está no contexto, mas ilustra a ideia)
const tensorCores = tf.tensor2d([
  [1, 0, 0],  // Erick - azul
  [0, 1, 0],  // Ana - vermelho
  [0, 0, 1]   // Carlos - verde
]);

console.log(tensorCores.shape); // [3, 3] → 3 pessoas, 3 cores
```

## Resumindo

| Conceito | Explicação |
|----------|------------|
| **Tensor** | Array multidimensional de números |
| **Rank (ordem)** | Número de dimensões (escalar=0, vetor=1, matriz=2, etc.) |
| **Shape** | Tamanho de cada dimensão (ex: `[3, 3]`) |
| **Dtype** | Tipo de dado (float32, int32, bool, etc.) |

> 💡 **Dica prática**: Como desenvolvedores web, geralmente usamos modelos já treinados (que já esperam tensores num formato específico). Mas entender essa transformação de dados reais → tensores numéricos é fundamental para saber *o que* alimentar o modelo!
