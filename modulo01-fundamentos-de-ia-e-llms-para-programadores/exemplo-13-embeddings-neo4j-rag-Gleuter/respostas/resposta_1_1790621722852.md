# Como Converter Objetos JavaScript em Tensores no TensorFlow.js

Olá! Essa é uma pergunta excelente e muito comum quando começamos a trabalhar com TensorFlow.js. Vou explicar de forma simples e prática, usando os exemplos que vimos no contexto.

## O que são Tensores no TensorFlow.js?

Antes de tudo, é importante entender que **o TensorFlow.js não consegue trabalhar diretamente com objetos JavaScript** — como dicionários (`{}`) ou valores primários (strings, números, booleans). Ele precisa de **dados numéricos puros**, organizados em estruturas que ele entenda.

Imagine que o TensorFlow.js é como uma caixa de ferramentas matemáticas: para funcionar, você precisa colocar dentro dela apenas números. Por isso, toda vez que você quiser usar um objeto JavaScript, você precisa transformá-lo em algo que o TensorFlow.js aceite.

## Passo a Passo: Convertendo Objetos em Tensores

Vamos usar o exemplo que temos no contexto. Temos um array de pessoas, cada uma com propriedades como `nome`, `idade`, `cor` e `localizacao`. Queremos criar um tensor que represente suas preferências de cor.

### 1. Identifique as características relevantes

No nosso caso, queremos focar nas **cores** como dimensão principal. Cada cor será representada por um valor numérico:

- **Azul** → 1 (presente)
- **Vermelho** → 1 (presente)
- **Verde** → 1 (presente)

As outras propriedades (idade, localização) podem ser tratadas de acordo com o seu modelo, mas para este exemplo vamos focar apenas na cor.

### 2. Transforme o objeto em um tensor

Veja como isso funciona na prática:

```javascript
// Objeto original (como no contexto)
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];

// Categorias disponíveis (para mapear cores para números)
const categorias = ['azul', 'vermelho', 'verde'];

// Cria o tensor para cada pessoa
// Cada linha = uma pessoa, cada coluna = uma característica (cor)
const tensorCor = [];
for (const pessoa of pessoas) {
  const row = [];
  // Para cada cor, verificamos se a pessoa prefere aquela cor
  if (pessoa.cor === 'azul') row.push(1);
  else if (pessoa.cor === 'vermelho') row.push(1);
  else if (pessoa.cor === 'verde') row.push(1);
  else row.push(0); // Caso contrário, é 0
  tensorCor.push(row);
}

console.log(tensorCor);
// Saída:
// [
//   [1, 0, 0],  // Erick prefere azul
//   [0, 1, 0],  // Ana prefere vermelho
//   [0, 0, 1]   // Carlos prefere verde
// ]
```

Neste exemplo, cada pessoa fica representada por uma linha num tensor. A primeira coluna representa a preferência por **azul**, a segunda por **vermelho** e a terceira por **verde**.

### 3. Usando a função `tf.tensor()` (se disponível)

Se você já estiver familiarizado com TensorFlow.js, pode usar a função nativa para converter arrays em tensores:

```javascript
import * as tf from '@tensorflow/tfjs';

// Array de matrizes (cada pessoa é uma linha)
const arrayDeMatrizes = [
  [[1, 0, 0]],    // Erick: azul = 1, outros = 0
  [[0, 1, 0]],    // Ana: vermelho = 1, outros = 0
  [[0, 0, 1]]     // Carlos: verde = 1, outros = 0
];

// Converte para tensor
const tensor = tf.tensor(arrayDeMatrizes);
console.log(tensor.shape()); // [3, 3]
```

Isso faz exatamente o que fizemos manualmente no exemplo anterior: transforma o array de objetos em uma estrutura numérica que o TensorFlow.js entende.

## Resumo Prático

| Passo | O que fazer |

| 3️⃣ | Crie um array onde cada linha representa uma pessoa e cada coluna uma característica |
| 4️⃣ | Converta esse array em tensor usando `tf.tensor()` ou construindo-o manualmente |
