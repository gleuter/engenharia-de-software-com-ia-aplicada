Olá! Vamos falar sobre **tensores** no TensorFlow.js de forma bem didática. 😊

## O que são Tensores?

No TensorFlow.js, **tensores são a estrutura fundamental de dados** — pense neles como **arrays multidimensionais que contêm apenas números**. O próprio nome "TensorFlow" vem disso: o fluxo de tensores através do grafo computacional.

> **Na prática:** Tensores são vetores ou listas em JavaScript onde todo o conteúdo é representado por números, para que algoritmos de machine learning possam aprender com padrões desses dados.

## Por que apenas números?

O TensorFlow.js **não entende objetos JavaScript, strings ou tipos primitivos** diretamente. Você **precisa converter** seus dados para uma estrutura puramente numérica — um Tensor.

## Exemplo Prático: Convertendo Dados Reais

Imagine que você tem dados de pessoas:

```javascript
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];
```

Para transformar isso em tensores, você converte cada propriedade em representação numérica:

### 1. **Idade** → Já é número, pode normalizar (ex: dividir por 100)
### 2. **Cor preferida** → *One-hot encoding* (uma coluna por cor):

| Pessoa | Azul | Vermelho | Verde |
|--------|------|----------|-------|
| Erick  | 1    | 0        | 0     |
| Ana    | 0    | 1        | 0     |
| Carlos | 0    | 0        | 1     |

### 3. **Localização** → Também vira one-hot encoding ou embedding

## Como Criar Tensors no TensorFlow.js

```javascript
import * as tf from '@tensorflow/tfjs';

// Tensor 1D (vetor)
const idades = tf.tensor1d([30, 25, 40]);

// Tensor 2D (matriz) - one-hot encoding das cores
const cores = tf.tensor2d([
  [1, 0, 0],  // Erick - azul
  [0, 1, 0],  // Ana - vermelho
  [0, 0, 1]   // Carlos - verde
]);

// Tensor 3D (ex: batch de imagens: [batch, altura, largura, canais])
const imagens = tf.tensor4d([...]);
```

## Resumo Visual

```
Escalar (0D)     →  número único:  5
Vetor (1D)       →  [1, 2, 3, 4]
Matriz (2D)      →  [[1, 2], [3, 4]]
Tensor 3D        →  [[[1, 2], [3, 4]], [[5, 6], [7, 8]]]
... e assim por diante
```
