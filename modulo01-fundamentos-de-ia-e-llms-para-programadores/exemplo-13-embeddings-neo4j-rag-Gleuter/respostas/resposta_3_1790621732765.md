Fazendo uma analogia simples: uma rede neural no TensorFlow.js é como um conjunto de operações matemáticas conectadas entre si, cujo objetivo é encontrar padrões escondidos nos dados.

Na prática, com o exemplo que vimos até aqui, o fluxo funciona assim:

1. **Você alimenta a rede** com dados de exemplo — no caso, a lista de pessoas com suas características (idade, cor preferida, localização) e a categoria correspondente de cada uma:
   - Erick → premium
   - Ana → medium  
   - Carlos → basic

2. **A rede tenta aprender os padrões** entre as características e as categorias.

3. **Você cria uma nova pessoa** e pede para o algoritmo determinar em qual categoria essa nova pessoa tem mais probabilidade de se encaixar.

**Detalhe importante:** o TensorFlow.js não entende objetos ou instâncias primitivas do JavaScript diretamente. Você precisa converter tudo para números, em uma estrutura chamada **Tensor**.

Por exemplo, para a propriedade "cor", transformamos em uma tabela binária (um processo chamado *one-hot encoding*):

|        | azul | vermelho | verde |
|--------|------|----------|-------|
| Erick  | 1    | 0        | 0     |
| Ana    | 0    | 1        | 0     |
| Carlos | 0    | 0        | 1     |

Assim, cada pessoa vira uma sequência de números que a rede consegue processar matematicamente.
